# DeepGuard-AI-Transformer-Based-Deepfake-Detection-Explainable-AI
I’m excited to showcase DeepGuard AI, an AI-powered deepfake detection system designed to identify manipulated facial images using Transformer-based deep learning.  The project leverages a Vision Transformer (ViT) model trained on the Deep Fake Detection Dataset (DFD) to classify facial images as Real or Fake.
